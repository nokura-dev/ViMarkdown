# Markdown機能追加サンプル

追加した記法を確認するためのサンプルです。
ノーマル／ビジュアルモードで表示し、挿入モードで原文を編集してください。

## 1. 箇条書き

- りんご
- みかん
  - 温州みかん
  - 夏みかん
    - 入れ子の項目
- **太字**、*斜体*、`コード`を含む項目

## 2. 番号付きリスト

1. ファイルを開く
2. 本文を編集する
   1. 見出しを付ける
   2. 内容を確認する
3. 保存する

### 途中の番号から開始

5. ここは5番から開始
6. 次は6番
7. 最後は7番

## 3. 引用

> 引用の1行目です。
> 引用の2行目です。**太字**と*斜体*も使えます。
>
> 別の段落です。
>
> > 入れ子の引用です。

## 6. 取り消し線

変更前：~~古い仕様~~

変更後：新しい仕様

通常の文字、~~取り消した文字~~、**太字**を同じ行に表示します。

~~**太字と取り消し線の組み合わせ**~~

## 7. タスクリスト

- [ ] 未着手のタスク
- [x] 完了済みのタスク
- [ ] **表示確認**を行う
  - [x] 箇条書きを確認する
  - [ ] 表の列配置を確認する
- [ ] クリック後にUndo／Redoを確認する

チェックボックスをクリックして状態を切り替えてください。
ノーマルモードの `u` で取り消し、`Ctrl+R` でやり直せます。

## 13. 定義リスト

Markdown
: 記号を使って文章の構造や装飾を表す記法です。

ノーマルモード
: 記法を反映した本文を表示するモードです。

挿入モード
: Markdownの原文を編集するモードです。
: 同じ用語に複数の説明を記述できます。

## 14. コード表示（言語別色分けなし）

インラインコード：`var total = price * count;`

### 言語名付きコードブロック

```csharp
using System;

var items = new[] { "りんご", "みかん" };
foreach (var item in items)
{
    Console.WriteLine(item);
}
```

### 言語名なしのコードブロック

```
# これは見出しに変換されません
- これは箇条書きに変換されません
~~これは取り消し線に変換されません~~
- [ ] これはチェックボックスに変換されません
```

### インデントによるコードブロック

    first line
    second line
    third line
