大きなページの応答性検証用データ

ファイルはUTF-8、改行はLFです。
大きな2ファイルは、ViMarkdownの原文上で4,000行・100,000文字です。
文字数には3,999個の改行を含みます。日本語を含むためファイルサイズは100KBではありません。
サロゲートペアや結合文字は使用せず、UTF-16単位でも100,000です。

large-many-rules.md
  区切り線1,000本、空行1,000行、本文2,000行。
  各区切り線の前に空行を置き、下線形式の見出しとして解釈されない構成です。
  区切り線以外のMarkdown記法は使用していません。

large-plain.md
  同じ行数・文字数で、区切り線だけを通常の本文「比較文」に置換しています。

small-page.md
  移動後の応答確認用。10行の小さなページです。

確認手順
1. 各mdファイルの内容全体を、それぞれ別の新規ページへ貼り付けます。
   ファイル名やコードフェンスは本文へ追加しないでください。
2. 小さなページで文字入力・カーソル移動を行い、操作感を確認します。
3. 区切り線の多い大きなページを通常モードで開き、先頭・中間・末尾へスクロールします。
   区切り線や文字の表示欠けがないことも確認します。
4. 小さなページへ戻り、文字入力・カーソル移動・ページ移動の応答を確認します。
5. 大きなページで挿入モードへ切り替え、そのまま小さなページへ移動して同様に確認します。
6. 区切り線のない大きなページでも同じ操作を行い、区切り線の有無による違いを比較します。
7. 各条件で数回往復し、応答低下が蓄積するか確認します。

貼り付け直後は保存と初回レイアウトが発生するため、処理が落ち着いた後の操作も比較してください。
入力で文字数が変わった場合は、元ファイルの本文へ戻して比較してください。
実機での応答性を確認するためのデータであり、性能計測や改善確認の実施結果ではありません。
