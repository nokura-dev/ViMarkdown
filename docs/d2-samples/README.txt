D2フェンス用の手動確認データ

normal.md: 通信・画像参照なしの正常系。
errors.md: 禁止構文と構文エラーの診断、および正常図への復帰。
images-template.md: assetsのPNG/JPEGを絶対パスで指定するテンプレート。
assets/sample.png, sample.jpg: この確認用に生成した96x64の色帯画像。

本文をViMarkdownへ貼り付け、リッチ表示・Markdown出力・DOCX出力を確認してください。
今回の生成環境向けに絶対パスを埋めた版はoutput/d2-samples/normal.mdにあります。
outputはGit管理対象外です。別PCでは画像の絶対パスを置き換えてください。
このデータの追加では自動テストを実行していません。
