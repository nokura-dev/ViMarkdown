# Markdown記法サンプル

ViMarkdownが対応しているMarkdownとD2フェンスの記法サンプルです。
`i` で原文を確認し、`Esc` で整形表示へ戻れます。
ノーマル／ビジュアルモードで表示し、挿入モードで原文を編集してください。

## 見出し・段落・装飾

# 見出し1
## 見出し2
### 見出し3
#### 見出し4
##### 見出し5
###### 見出し6

別の見出し（Setext形式）
========================

小さい見出し（Setext形式）
--------------------------

通常の文章、**太字**、*斜体*、***太字と斜体***、`インラインコード`。
日本語・English・絵文字 👩‍💻 を混在できます。
このような通常の改行も、表示に反映されます。

空行で段落を分けます。記号をそのまま書く場合は、\*装飾しない文字\* のようにエスケープします。

## 7. タスクリスト

- [ ] 未着手のタスク
- [x] 完了済みのタスク
- [ ] **表示確認**を行う
  - [x] 箇条書きを確認する
  - [ ] 表の列配置を確認する
- [ ] クリック後にUndo／Redoを確認する

チェックボックスをクリックして状態を切り替えてください。
ノーマルモードの `u` で取り消し、`Ctrl+R` でやり直せます。

## 9. 定義リスト

Markdown
: 記号を使って文章の構造や装飾を表す記法です。

ノーマルモード
: 記法を反映した本文を表示するモードです。

挿入モード
: Markdownの原文を編集するモードです。
: 同じ用語に複数の説明を記述できます。

## 11. 画像

挿入モードで `Ctrl+V`（macOSでは `Cmd+V` も可）で画像を貼り付けると、画像データをDBに保存し、次の形式のMarkdownを挿入します。
以下は書き方の説明です。実際の画像IDは貼り付け時に作成されます。


## 12. D2フェンス

言語名を `d2` にしたコードブロックは図として表示します。
`i` で原文を編集して `Esc` で戻ると図が更新されます。
テーマはNeutral Grey（ID 1）です。Markdown／docx出力では図をPNGとして出力します。

### フローと接続ラベル

```d2
direction: right
編集: Markdownを編集
保存: SQLiteに保存
表示: リッチ表示
編集 -> 保存: 自動保存
保存 -> 表示: 表示を更新
```

### 分岐と図形

```d2
direction: down
開始: 開始 {shape: oval}
確認: 入力は有効か {shape: diamond}
完了: 保存完了 {shape: oval}
再編集: 入力を修正
開始 -> 確認
確認 -> 完了: はい
確認 -> 再編集: いいえ
再編集 -> 確認
```

### グループとデータベース

```d2
direction: right
アプリ: ViMarkdown {
  エディタ: Markdown編集
  レンダラー: D2描画
  エディタ -> レンダラー: 図のコード
}
DB: ノートと画像 {shape: cylinder}
アプリ.エディタ -> DB: 保存
```

### 文字の装飾

```d2
direction: down
通常: 日本語 English 123
太字: 日本語 English 123 {style.bold: true}
斜体: 日本語 English 123 {style.italic: true}
通常 -> 太字 -> 斜体
```

同梱MigMixには斜体フォントがないため、D2の斜体指定はRegularで代用します。

### Markdownラベル

```d2
説明: |md
  # 図の説明
  **太字の本文**

  - 日本語の項目
  - English item
|
```

### D2内の画像と対応範囲

D2内の画像は、ローカルPNG／JPEGの絶対パスのみ対応します。
次は原文のテンプレートです。自分の画像の絶対パスへ置き換え、フェンスの言語名を `d2` にすると描画できます。

```text
写真: {
  shape: image
  icon: /absolute/path/to/photo.png
}
```

Windowsでは `C:/Users/ユーザー名/Pictures/photo.png` のような絶対パスを指定します。
import、URL画像、SVG、相対パス、Layers／Scenarios／Stepsは非対応です。
変数展開、引用符外のエスケープ、ブロックキー、ブロックラベル内の画像・HTMLも非対応です。
