# ステップ8の受入確認

自動チェックではDOCXの個別出力、同名ページ、日本語、強調、表、画像・図・欠損代替画像の内部埋め込み、再オープンとOpen XMLスキーマ検証、WAL使用中のDBバックアップから本文と画像の読み出しを検証します。

以下は実機で記録する項目です。OS、CPU、対象アプリ名・バージョン、結果とスクリーンショットを残してください。対象アプリの指定がないため、Microsoft Word（macOS/Windows）を基本対象、必要に応じてLibreOffice・Pagesも追加対象とします。

- 各OS・CPU用ZIPを別の端末へコピーし、READMEの手順で導入する。.NET未導入状態で起動し、日本語のページを作成・終了・再起動して保存を確認する。
- macOSでは.appをApplicationsへコピーする。WindowsではInstall.ps1によるスタートメニュー登録とそこからの起動を確認する。署名・公証は別工程のため、その状態も記録する。
- 見出し、太字、斜体、コード、複数行、日本語・絵文字、表、縦横画像、高DPI画像、Mermaid図を含むページを作る。個別DOCXを生成する。
- DOCXだけを別フォルダ・別端末に移し、Wordで修復要求なく開けること、書式・罫線・全画像・図・ページ間改ページを確認する。保存して再度開く。
- 図の構文エラー・未設定、欠損画像で、コードまたは代替画像と診断ファイルが残ることを確認する。
- バックアップ後に元DBと別のパスでバックアップコピーを開き、ノート一覧・本文・画像を確認する。通常DBに上書きしない。
- 狭いウィンドウでツールバーを横スクロールし、DOCXとバックアップへ到達できることを確認する。

両OSの導入・GUI起動・Word表示が完了するまでは、ステップ8の受入条件を検証済みとは扱いません。
